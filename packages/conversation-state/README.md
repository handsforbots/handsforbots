# @handsforbots/conversation-state

Explicit conversation state for Hands for Bots: a small, structured, auditable record of topic, goal, entities, decisions, sourced facts and pending items, changed only by checked operations and sent with every request.

Part of [Hands for Bots](https://github.com/handsforbots/handsforbots), a headless multimodal and action layer between users, GUIs and agents.

## Install

```bash
npm install @handsforbots/conversation-state@alpha @handsforbots/core@alpha
```

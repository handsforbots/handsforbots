# @handsforbots/a2ui

Plugin. Headless A2UI 1.0 surface host for Hands for Bots, managing surface state over @a2ui/web_core while leaving rendering to the host app.

Part of [Hands for Bots](https://github.com/handsforbots/handsforbots).

## Install

```bash
npm install @handsforbots/a2ui@alpha @handsforbots/core@alpha
```

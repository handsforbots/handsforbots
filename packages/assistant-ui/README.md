# @handsforbots/assistant-ui

UI. assistant-ui runtime for Hands for Bots: use assistant-ui components as the conversation surface over any H4B transport.

Part of [Hands for Bots](https://github.com/handsforbots/handsforbots), a headless multimodal and action layer between users, GUIs and agents.

## Install

```bash
npm install @handsforbots/assistant-ui@alpha @handsforbots/core@alpha @handsforbots/react@alpha
```

Also needs: `@assistant-ui/react`, `react`.

# @handsforbots/guided

Plugin. Guided tours and on-screen highlights that assistants, agents and users can trigger (successor of v1 GUIDed).

Part of [Hands for Bots](https://github.com/handsforbots/handsforbots), a headless multimodal and action layer between users, GUIs and agents.

## Install

```bash
npm install @handsforbots/guided@alpha @handsforbots/core@alpha
```
